# 设计端个人任务明细导出

设计端在“我的任务”右上角点击“导出我的任务明细”，或打开左侧“任务明细导出”。选择周、月或自选日期后保存 `.xlsx` 文件。周统计为北京时间周一至周日；自选范围包含开始日和结束日，最多 366 天。

Excel 包含五张表：

| 工作表 | 内容 |
| --- | --- |
| 个人汇总 | 完成任务数、事项数、分类数量、点数合计及数据问题数 |
| 任务明细 | 任务名、内容数量、SKU/主图/详情页等数量、任务点数、提交和确认完成时间、品牌产品、运营、任务编号及原需求表文件名 |
| 事项明细 | 原事项类型、数量、单位、点数、备注及需求表行号 |
| 统计说明 | 时间、数量、点数、返工与个人归属口径 |
| 数据问题 | 推定完成时间、历史缺失、分类不明确及点数缺失等说明 |

## 统计口径

- 按运营确认完成时间归期；设计提交时间单列。待确认、进行中、推定完成时间不进入正式完成合计。已确认但尚未封存的任务可以计入。
- 数量取需求表事项工作量，不按上传文件数量统计。SKU、主图、详情页等只从明确事项类型归类。通用修改、尺寸适配等保留原事项名称，不能从归档目录反推类别。
- 详情页“张”和“屏”分别统计，视频保留“条”，六面图不再次乘以六。其他类型/单位按实际明细生成数量列。
- 优先使用保存的事项点数及负责人对同一完成记录的校准，校准时间单列。缺失点数如按当前标准补算会注明；无法补算则留空，合计仅包含已知点数。
- 按统计截止时的历史任务归属导出。多人接力不自动拆分完成点数。截止时已回退为未完成的任务不计入；同一任务在一次报表中只列一行。
- 跨周返工后重新确认，可能同时出现在两个周报；月报按月末最新完成轮次计一次，周报相加未必等于月报。现有数据不能额外拆算返工量。
- 没有符合条件的任务仍可导出空明细和零汇总；无法还原的历史会明确提示，不能据此认定没有工作量。

## 更新与权限

负责人主机与设计端需要同时更新，先更新负责人主机。旧主机会提示需要更新，设计端离线时不可导出；导出读取主机的历史记录，不使用本地离线缓存。

主机接口 `personal-report-data` 使用已认证设计师身份，忽略客户端传入的人员参数。只返回其周期截止时拥有的任务，不开放负责人分析包或其他成员事件。无法确认历史归属的记录仅作匿名说明，不返回任务名、文件名、编号或数量。已移出成员沿用现有访问禁用规则。

导出不更改任务、需求表、NAS 文件或点数。负责人端原有分析包导出继续保留。

## 验证

```powershell
npm test
node node_modules/electron/install.js
New-Item -ItemType Directory -Force ui/vendor
Copy-Item node_modules/lucide/dist/umd/lucide.min.js ui/vendor/lucide.min.js
node node_modules/electron/cli.js scripts/check-personal-report-ui.cjs
```

界面检查使用独立测试数据库和隐藏窗口，覆盖周/月/自选日期、日历、取消保存、非法范围、离线、旧主机提示及负责人入口。检查结果在 `checks/personal-report-ui/`，包含截图和使用示例数据生成的 Excel，不含真实 NAS 数据。
