# 设计协作工作台

基于公司 NAS 的设计需求、任务流转和产物归档系统。此仓库统一保存三个客户端，与 Relay 图片工作台分开维护。

| 客户端 | 当前安装包 | 源码目录 |
| --- | --- | --- |
| 负责人端 | 0.6.29 | desktop/、ui/、core/ |
| 设计端 | 0.6.29 | desktop/、ui/、core/ |
| 运营端 | 0.2.13 | operator/、core/ |

安装包在 Releases 下载。负责人主机应先更新，再更新其余客户端。三个客户端均从当前源码构建。

## 开发和打包

使用 Node.js 24 或更新版本，Windows 下构建安装包：

```powershell
npm ci
npm start
node scripts/build.cjs manager nsis
node scripts/build.cjs designer nsis
node scripts/build-operator.cjs
```

构建结果保存在 release/。两端各自使用独立的应用标识和用户数据目录。

## 0.6.22 回退提速

回退到待封存只撤销当前任务封存标记，保留文件，不执行全量 NAS 扫描。其他环节回退只核对当前需求表，保留版本、占用与重复原表校验。98 项相关测试、两端启动与安装包源码核验通过。另一对话未发布的封存一致性修改未包含在本版本中。


## 0.6.23 更正69码后回退

负责人可在回退弹窗勾选采用原表中更正后的69码，将更正与回退一起保存。仅允许同一固定任务编号、仅69码变化的原表；权限、版本、重复原表、Excel占用和文件哈希检查保留。旧交付、原码及文件保留为历史，不移入新码目录。101 项相关回归测试通过。
